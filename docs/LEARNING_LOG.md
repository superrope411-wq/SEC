# Learning Log

This is a running record of what Ronin learns in a Coursera course and how each
lesson changes the Quarterly Earnings Change Monitor. It shows, step by step,
which ideas came from the course, what was built because of them, and what
Ronin can explain about each change without help.

## Rules

- **Append only.** New entries go at the bottom. Earlier entries are never
  edited or deleted, even if they turn out to be wrong.
- **Corrections are new entries.** If an earlier entry was mistaken, add a new
  entry that names the earlier one by its number and says what changed.
- **The lesson is in Ronin's words.** The "Lesson" field records what Ronin
  took from the course, not a summary written by AI.
- **Every change is traceable.** Each entry links the commits, pull requests
  and files it touched. If a lesson led to no code change, the entry says so
  and why.
- **AI assistance is stated.** Each entry says what Claude implemented and what
  Ronin did, so the log can be cited honestly in applications.

## Entry format

Copy this template for each new entry and number entries in order.

```markdown
### Entry N: <short title> (YYYY-MM-DD)

- **Course:** <course name>, <module or week>, <lesson title>
- **Lesson (Ronin's words):** <what Ronin learned>
- **Change to the scanner:** <what was changed, or "none" and why>
- **Links:** <PR #, commit hashes, files changed>
- **Why:** <how the lesson justifies the change, and what was considered instead>
- **Who did what:** <Ronin's part; Claude's part>
- **What Ronin should be able to explain:** <the questions Ronin can answer about it>
- **Corrects:** <Entry M, if this entry corrects an earlier one; otherwise omit>
```
